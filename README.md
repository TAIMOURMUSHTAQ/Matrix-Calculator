# 🧮 Matrix Calculator (C++)
A simple C++ console-based Matrix Calculator that supports:
1- Matrix **Addition**
2- Matrix **Subtraction**
3- Matrix **Multiplication**
4- Matrix **Transpose**
Supports matrices up to 20x20 with input validation for dimensions.

## 🔧 How It Works
1. Enter the size and elements of two matrices.
2. Choose an operation: `+`, `-`, `*`, or `t`.
3. View the result and choose to continue or exit.
